## 后台：分类折叠、筛选、最新日志

### 写作后台

- 加入密码验证，只有博主本人能进入
- 文章列表增加搜索（按标题/分类过滤）
- 列表显示文章分类
- 列表支持隐藏/显示文章（隐藏的文章移到草稿，不参与构建）
- 音乐面板支持上传音频、封面、歌词
- 支持插入音乐平台歌曲（Meting），附搜索功能
- 保存/删除按钮固定在滚动区外
- 侧边栏和主区滚动条可见
- 文章列表按分类分组，分类标题可折叠
- 列表筛选：全部 / 已发布 / 隐藏
- 显示/隐藏按钮改为文字按钮（原来用眼睛图标）

### 博客

- 接入 MetingJS，可插入网易云等平台的歌曲
- 新建音乐目录与播放器示例文章
- 后台入口不再套用主题布局

## 主题：Butterfly 与深海背景

### 主题与外观

- 换用 Butterfly 主题（简体中文）
- 主背景改为深海蓝渐变
- 背景叠加深海纹样（水波、气泡、小鱼），缓慢漂移
- 首页与各页横幅使用宫殿夜景
- 桌宠支持拖动，位置会记住
- 语言切换收进右侧工具栏，单个按钮循环切换简/繁/EN

### 功能

- 新增网页写作后台 `/admin/`
- 文章列表支持直接删除
- 图标字体等 CDN 资源本地化（解决图标丢失）

## 建站：Hexo + GitHub Pages

### 建站

- 使用 Hexo 7 + Butterfly 主题
- 托管在 GitHub Pages
- 绑定自定义域名 `keivenblog.me`
- 接入 Utterances 评论（数据存在 GitHub Issues）
- 配置 RSS、本地搜索、字数统计

### 部署

- 通过 GitHub Actions 自动构建发布
- 因 github.com 直连困难，改用 GitHub API 推送

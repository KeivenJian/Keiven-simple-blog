## 换成你自己的音乐

1. 把 mp3 文件放进 `source/music/` 目录
2. 封面图放进 `source/images/` 目录
3. 把文章里的地址改成你的文件名

写法：

```markdown
{% aplayer "歌名" "歌手" "/music/你的文件.mp3" "/images/你的封面.jpg" %}
```

## 常用参数

| 参数 | 作用 |
| --- | --- |
| `narrow` | 窄版播放器 |
| `width:600px` | 指定宽度 |
| `lrc:/music/歌名.lrc` | 加载歌词文件 |

示例：

```markdown
{% aplayer "歌名" "歌手" "/music/song.mp3" "/images/cover.jpg" "narrow" "width:420px" %}
```

## 注意

- 音频文件建议 5MB 以内，太大拖慢仓库
- 外链音频必须能直接访问（不是网页链接）
- 浏览器通常会拦截自动播放，需要用户手动点
- 请使用有授权的音乐
